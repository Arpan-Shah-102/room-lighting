# Room Lighting
### Description
Room Lightiing is a project I created so I can add lights to my room. Before, the lighting in my room was bad, there only really being two options. 1. Using the large light or 2. Using the smart light. If I used the smart light, it was not big enough to light the room on it's own so I could never reallyuse it. With my improved room lighting, all the lights I added make it possible to use my smart lamp as well as the new lights.
